# 任务思维链

请严格按照以下三个步骤对 <当前步骤检索内容> 进行处理：

## 第一步：限定特征提取
从文本片段中，提取所有明确提及的业务规则适用边界（客观环境）。
*   **提取维度**：[卡等级]（如白金卡）、[卡组织]（如银联）、[卡/附属卡]、[账户状态]、[业务场景]、[渠道/时效]等。
*   **约束**：如果文本中未提及某个维度的限定，一律标记为 `[未说明]`，**严禁自行推测**。

## 第二步：关联业务原子规则提取（核心步骤）

仔细通读当前检索内容，提取与原始问题相关的所有业务规则，并强制转化为 `**IF** [条件] **THEN** [结果]` 的原子格式。

在此步骤中，你必须**以最高优先级**遵守以下三大铁律：

**铁律 1：绝对禁止逻辑“脑补”（反过度推理）**
*   **绝不允许补充文档中未提及的隐含条件！** 即使你基于常识认为规则在逻辑上存在漏洞。
*   **操作**：如果原文的描述有条件缺失，必须在 IF 或 THEN 中使用 `[原文未提及]` 或 `[条件缺失]` 作为占位符填补。
    *   *错误示例（脑补）*：原文“分期提前还款需收违约金” -> `IF [申请提前还款] THEN [收取剩余本金3%的违约金]`（脑补了3%）。
    *   *正确示例（占位）*：原文“分期提前还款需收违约金” -> `IF [申请提前还款] THEN [收取违约金，具体比例[原文未提及]]`。

**铁律 2：完整保留语法歧义（禁止自行决断）**
*   知识库原文极可能存在表述不清或歧义。**当一段话存在两种或多种解读可能时，必须将每种解释分别保留，写成多个独立的原子规则！**
*   **绝对禁止**你自行判断哪种解释更合理。把选择权留给后置的仲裁专家。
    *   *示例*：原文“首年免年费，刷卡5次免次年年费（部分特殊卡种除外）”
    *   *必须拆分为两条分支*：
        *   规则A：`IF [是非特殊卡种] THEN [首年免年费，且刷卡5次免次年年费]`
        *   规则B：`IF [是特殊卡种] THEN [首年及次年年费收取规则[原文未明确说明，存在除外情况]]`

**铁律 3：彻底的原子性（消除 AND/OR）**
*   每个规则必须是最小的独立逻辑单元。
*   `IF [条件A 或 条件B] THEN [结果X]` -> 必须拆分为：
    1. `IF [条件A] THEN [结果X]`
    2. `IF [条件B] THEN [结果X]`
*   原汁原味：尽量使用原文的词汇，通过引用符号或摘抄原话来保证原意不被篡改。

## 第三步：四要素检查
在输出前，逐项核对你提取的每一条规则是否具备以下四个要素。如果确实没有，必须显式写明“缺失”：
1. **业务实体**：具体的卡种、业务名词。
2. **触发条件**：IF 后的内容。
3. **对应结果**：THEN 后的内容。
4. **业务背景**（可选）：规则适用的前置环境。
